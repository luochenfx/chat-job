chat-job 使用说明（Windows 绿色版）
====================================

这是一个跑在你自己电脑上的求职投递助手：用本机真实 Chrome / Edge 打开 BOSS 直聘与智联招聘，
按「城市 × 关键词」扫描岗位，按规则筛选后交给 AI 判断投不投、并生成招呼语；
运行期间还会值守未读消息。两个平台可同时运行，各自扫描、各自值守。

每个平台各用自己的账号，仅供本人使用。控制台只监听本机 127.0.0.1，数据全在本目录里，
不会上传到任何服务器。


一、怎么启动
------------
1. 把整个文件夹解压到**你自己有写权限的位置**，例如 D:\chat-job
   不要放在 C:\Program Files 下（那里写不进数据库和浏览器配置）。
2. 双击 start.bat。
3. 等几秒，控制台页面会自动打开（http://127.0.0.1:8080/）。
   如果没自动打开，就自己用浏览器访问这个地址。
4. 想停止：直接关掉黑色的命令窗口。

换端口：`start.bat 8081`，或先 `set CHAT_JOB_PORT=8081` 再双击。


二、第一次使用（大约 5 分钟）
------------------------------
1. 「系统」页：确认「patchright driver」是绿灯、浏览器能被识别。
2. 点「打开登录页」，在弹出的浏览器窗口里扫码登录 BOSS 直聘，
   登录完成后回控制台点「探测登录」确认。
   这个浏览器窗口是专用 profile，和你日常用的浏览器互不影响。
   两个平台各有一份独立 profile：启用智联后，还要在「系统」页对「智联招聘」那一行
   单独扫码登录一次，BOSS 的登录态不会共享过去。
3. 「配置」页：新增一个模型提供商（Base URL / 模型名 / API Key），
   填写个人介绍与搜索条件（城市、关键词）。
4. 「任务」页：先用演练模式（DRY_RUN）跑一轮看看流程，确认无误再用正常模式。
5. 可选——「系统」页的「告警通知」：填企业微信群机器人的 Webhook 地址，出事时手机能收到；
   不填则告警只写 data\logs\chat-job.log。三个开关分别管「异常」「进入待命」「时段结束」，
   后两类每天都会发一次，嫌烦可以单独关掉，别把整个告警关掉。

注意：演练模式**不是只读**——它仍会真实浏览平台、真实消耗 token，
点开会话就会清掉未读红点，这些消息之后不会再被值守处理。
它只保证「不投递、不回复」。


三、数据在哪
------------
data\                    数据库与日志（chat-job.db、logs\chat-job.log）
browser-data\<平台>\      各平台的浏览器登录态（体积会很大，几百 MB 属于正常）

备份 = 复制这两个目录。升级时也只保留这两个目录。


四、升级 / 卸载
----------------
升级：把新版解压到别处，然后用旧的 data\ 和 browser-data\ 覆盖新包里的同名目录
      （或把新包的 app\ runtime\ build\ scripts\ start.bat 复制到旧目录里）。
卸载：删掉整个文件夹即可，不写注册表、不留后台服务、不装驱动。

⚠ 不要把 data\ 拷给别人：里面的 API Key 与 Cookie 是用 Windows 账户加密的
  （DPAPI），换台电脑或换个 Windows 用户都解不开，对方会看到「未配置」；
  而浏览器登录态交出去等于把账号的访问权限一起交出。


五、常见问题
------------
- 控制台打不开 / 页面是别人的东西
    8080 端口被别的程序占了。换端口：start.bat 8081

- 「patchright driver 不可用」
  说明包里缺 build\patchright-driver 或 runtime\node.exe，重新解压完整包。

- 提示找不到 Chrome / Edge
  需要本机装有 Edge（Win10/11 自带）或 Chrome。装有但没识别到，
  可在控制台「系统」页看实际解析结果。

- 任务刚启动就 LOGIN_LOST
  登录态过期了。「系统」页按平台分行，对出问题的那一行点「打开登录页」重新扫码。

- 任务显示 WAITING_DUTY
  正常：当前不在值守时段内（默认 09:00–22:00，可在「配置」页改）。

- 窗口一闪就退出
  双击是看不到原因的，请从 cmd 里运行 start.bat，或在 data\logs\chat-job.log 看末尾报错。


六、边界与风险
--------------
- 它会在第三方平台上执行真实操作。请用小号试跑、保留默认配额与随机间隔，
  遇到异常让它停机（熔断），不要手动绕过。
- 使用本工具产生的任何账号风险由使用者自负。
- 值守回复单条 ≤ 60 字；命中敏感词（薪资、面试时间、联系方式等）整条不发。
  AI 回复默认关闭，打开前请先读懂控制台里的出站校验说明。
